# 从一件顺手的小事开始

如果你已经有日常使用的 coding agent，先选一个最有感觉的部分。

| 你现在想改善什么 | 建议的第一步 |
| --- | --- |
| 屏幕太刺眼，几种工具配色不一致 | [试羊皮纸主题](themes.md)，先把宿主终端的底色一起调整 |
| Pi 输入区和状态栏不够顺手 | [Pi 配方](pi.md)，分别安装输入框与 HUD |
| 同时开几个 agent，经常找不到谁在等回复 | [Herdr 工作台](herdr.md)，先看 Radar |
| 在电脑上生成的报告，离开桌子就不想读了 | [conv-docs](conv-docs.md)，从一个演示文件开始预览 |
| 每个项目都装了一大堆技能 | [dynamic-skills](skills-and-handoffs.md)，只启用这个项目需要的部分 |
| 想让另一个执行环境接手有边界的任务 | [cd-connect](skills-and-handoffs.md)，先写清范围和验收条件 |

下载资源包后，在根目录运行 `python3 scripts/verify.py` 检查文件。主题和配置文件可以直接阅读；`presets/` 中的文件是**配置片段**，合并其中需要的字段即可，不能拿它们覆盖整份日常配置。

`catalog.json` 记录本次选择的项目提交和 npm 包版本。`patches/` 保存三项工具的当前改动；[还原说明](snapshots.md)解释如何得到可运行的完整源码。默认材料不包含账号配置、认证文件、私人端点或真实会话。

这些工具各有前提。Pi 需要自己的模型账号；移动阅读需要运行中的服务和可达的网络；cd-connect 需要对应版本的 DSH Desktop。先弄清自己想解决的问题，再决定要带走几件。
