# 我想怎么用这套工具

> 演示文档 · 不含真实项目、账号或会话数据

我想把平时在用的工具整理到一起，也把它们怎么配合说清楚。你可以先挑自己感兴趣的部分，不需要一次全装上。

## 先从一个具体问题开始

比如，想换一套配色，就先试主题；想在手机上读报告，就先拿一份文档试试。觉得合适了，再放进日常环境。

| 什么时候 | 我会做什么 |
| --- | --- |
| 开始之前 | 讲清楚问题，一起讨论方案 |
| 正在修改 | 看看进展，有疑问继续沟通 |
| 做完之后 | 回到原来的需求，检查结果 |

## 一小段代码

```python
def pack_for_today(tools):
    return [tool for tool in tools if tool.is_useful_today]
```

## 用过之后，再看看

- 这份说明离开聊天后还能读懂吗？
- 结果是否真的解决了最初的问题？
- 下一位使用者能复现哪一部分？

哪里还不太好用，或者有更合适的做法，都可以继续讨论。
