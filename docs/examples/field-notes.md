# 小獭的工作札记

> 演示文档 · 不含真实项目、账号或会话数据

今天的目标很简单：把一个想法写清楚，再让它成为可以检查的成果。

## 先带走这个结论

让工具承担重复劳动，让人保留目标、取舍与验收。一个舒服的工作台，应该帮助你更容易看到正在发生的事情。

| 阶段 | 留下什么 |
| --- | --- |
| 开工前 | 目标、边界和完成标准 |
| 工作中 | 可见的状态与清楚的交接 |
| 完成后 | 实际改动、验证结果与限制 |

## 一小段代码

```python
def pack_for_today(tools):
    return [tool for tool in tools if tool.is_useful_today]
```
